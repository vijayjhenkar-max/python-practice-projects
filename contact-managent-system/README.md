# Python Contact Management System

A simple command-line Contact Management System built using Python. This project allows users to manage their personal contacts through an interactive menu.

## Features

- **Add Contact:** Add a new contact with name, phone number, place, and additional details.
- **View Contacts:** Display all saved contacts.
- **Search Contact:** Search for contacts using their names.
- **Update Contact:** Modify existing contact information.
- **Delete Contact:** Remove a contact from the contact list.
- **Phone Validation:** Validate phone numbers to ensure they contain 10 digits and start with 6, 7, 8, or 9.
- **Duplicate Checking:** Prevent duplicate names or phone numbers.

## Technologies Used

- Python 3
- Dictionaries
- Lists
- Functions
- Loops and Conditional Statements
- String Methods
